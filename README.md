# AZ Makes — Akhi + Zy

Six editable HTML pages in dist, shared style.css + brand.css, and vanilla script.js. Serve dist with any static web server; no build step.

## Brand and navigation
The original full-width cinematic desktop design is restored, with horizontal top navigation, a large studio hero and in-scene tools row. The current mobile design remains, with a compact header and menu. Six separate pages, rounded cards, and light/dark mode are preserved.

The toolkit contains n8n, Make, Zapier, ChatGPT, Claude, Canva, Codex, Excel, Notion, Google Workspace, Netlify, Vercel, and GitHub. These are tools shown in the portfolio; the website is published through Sites.

## Original creative collection
Zy’s Creative Sample replaces the previous external Canva collection with three original generated studio concepts: Violet Cursor Sculptures, Zy Creative Identity, and Orbit Light Study. Clicking a study opens its full artwork. No client commissions are claimed. Akhi’s original three portfolio demos and n8n learning showcase retain their original-source links. Demos contain fictional sample content; no workflow executes here.

## Loading and motion
The Home loading scene shows Akhi on the right and Zy approaching him with sequential rendered poses. Progress is based on critical image completion, displayed on Akhi’s laptop. The scene has a brief arrival hold, Skip intro, a timeout, reduced-motion fallback, and no-JavaScript fallback supplied in the HTML. Other pages open directly for fast navigation.

Room/foreground parallax, cursor lighting, lightweight particles, tilt, Zy reactions, the spark game, and a keyboard easter egg remain. Ambient sound is user initiated. Zy’s chatbot uses local preset replies and has no AI connection.

## Film
assets/az-makes-story.mp4 is a 30-second composited POV film. Zy enters the room, sees Akhi working, and the camera moves into his computer display to reveal Websites, Smart automation, Creative design and Custom projects. Generated character poses, camera movement, captions and original synth sound bring the scene to life. This is composited artwork animation, not a fully rigged 3D production. 1280x720 / 24fps / H.264 and AAC. Video loads on request and pauses when closed.

Preferred address: website.azmakes.studio. The parent domain azmakes.studio must be registered by the owner before it can be connected. No purchase or custom-domain activation has occurred. See CUSTOM-DOMAIN.md for the handoff.

## Contact and editing
Contact prepares an email draft to the inbox published on the user-supplied portfolio. The visitor reviews and sends it in their email app. No submission server is configured. Change SITE_CONFIG in script.js to change the inbox. Edit page copy in each HTML file; brand.css contains the latest design layer.

The working checkout and all deliverables live under D:/Finished projects/AZ-Makes/outputs. The previous chat output location is a junction to that folder, preserving existing download links. Historical versions are retained separately from the current website.
